# 一言：长内容信息子弹

把长内容蒸馏成一组 Markdown 无序列表。每颗子弹是逻辑自洽的分析段落，忠实于原文观点，可独立阅读和发布。

## 输入与输出

输入可以是播客逐字稿、长文章、博客或视频文字稿，不限长度和语言；默认输出中文。

输出只有无序列表：不加标题、分节、编号、导语或总结。信息密度决定子弹数量，不凑数、不平均分配篇幅。

## 子弹标准

- **自洽**：每颗子弹是完整思想单元，包含论点、支撑事实或逻辑，以及自然收束；读者无需上下文也能理解。
- **长度**：通常由 5-8 句组成，是一段密实但可读的长呼吸，不写标签式短句。
- **节奏**：以句号为主要连接符，每句推进一层判断；逗号承担句内停顿，分号只用于紧密并列。
- **收尾**：适合时用一句精炼判断收束，但不强求每段都造金句。
- **顺序**：大致沿原文叙事线，以逻辑连贯优先；同一观点散落多处时合并。

## 归因与事实

- 默认省略主语，直接陈述观点。
- 只有当人物身份、行动或原话本身构成论据时才写人名。
- 几乎不用“我”；发言人不明时不猜，直接表达能够确认的观点。
- 不写“嘉宾认为”“主播提到”“有人指出”“文章指出”“据报道”等泛化归因。
- 保留原文中的数字、人名、公司名和时间点；它们是信息密度的骨架。
- 允许添加极薄的解释性连接，点明原文已经蕴含的因果关系；不得把新推断伪装成原文事实。
- 默认不添加原文之外的事实、数字或案例。确有必要时，必须能可靠核实并自然标明来源。
- 原文中传播力强的原话可用引号保留，每篇通常不超过 3-5 处。

## 逐字稿清理

- 删除广告、节目宣传、开场寒暄、口头禅、无信息量附和、重复和未完成句。
- 合并不同发言者对同一观点的反复确认，保留信息最完整的版本。
- 跳过无价值的跑题闲聊；跑题产生独立洞见时可以保留。
- 不按发言者平均分配内容，信息密度决定篇幅。

## 工作流

1. 通读全文，识别主题、核心论点、证据和论点之间的关系。
2. 标记值得独立成段的思想单元，并将散落的同类信息归拢。
3. 逐颗改写，使用句号推进论证，保留数据锚点，并在适合处收束。
4. 检查每颗是否独立可读、是否忠于原文、是否存在水分或无依据的新事实。
5. 去除模板化 AI 文风，重点改写：
   - “不是 X，而是 Y”“不仅仅是 X，更是 Y”等机械对照句；
   - “这很关键”“值得深思”“归根结底”“说到底”“本质上”等空判断；
   - 宏大时代起手、哲学升华收尾、连续排比否定；
   - “赋能、闭环、赛道、底层逻辑、重新定义、彻底颠覆”等缺乏具体含义的词；
   - 模板化比喻、过度类比和空心对仗金句。

## 最终检查

- 每颗子弹是否只有一个清晰主张，并有足够支撑？
- 数据锚点和限定条件是否保留？
- 主语是否只在必要时出现？
- 是否添加了无法确认的事实或把可能性写成确定性？
- 整组子弹是否有叙事流动，而不是杂乱堆砌？

不要照搬原文句式，也不要在子弹末尾追加“这一点值得深思”之类的评论。
